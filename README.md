# Anna Nutrition

Статический многоязычный сайт Анны Бородиной, созданный на основе контента старого Tilda-сайта. Проект не использует фреймворк, сборщик или серверную часть и может размещаться на обычном статическом хостинге.

## Структура проекта

- `index.html` — русская версия;
- `en.html` — английская версия;
- `ua.html` — украинская версия (`lang="uk"`);
- `style.css` — общие стили и адаптивная верстка;
- `script.js` — мобильное меню, анимации появления, FAQ, контактная форма, галереи и предпросмотр гайдов;
- `assets/images/` — локальное изображение секции «Обо мне»;
- `assets/credentials/` — 10 изображений сертификатов;
- `assets/testimonials/` — 21 изображение отзыва;
- `assets/guides/` — демонстрационные PDF-гайды.

Русская и украинская версии содержат секцию отзывов. В английской версии этой секции сейчас нет. Все страницы используют один CSS-файл и один JavaScript-файл, поэтому общие изменения интерфейса следует проверять во всех трех версиях.

## Как устроен сайт

Страницы состоят из главного экрана, информации об Анне, образования и сертификатов, описания подхода, запросов, услуг, гайдов, FAQ, контактного блока, дисклеймера и footer. Навигация внутри страницы работает по якорным ссылкам.

Контактная форма не отправляет данные на сервер: JavaScript формирует локализованный черновик письма через `mailto:`. Запись на консультацию ведет на Calendly. Галереи сертификатов и отзывов собираются из файлов в `assets` по значениям `data-*` атрибутов.

## Изображения и внешние зависимости

Изображение в секции «Обо мне» хранится локально: `assets/images/about-nutrition-frame.png`.

Главная портретная фотография подключена с Tilda CDN. Шрифты Cormorant Garamond и Inter загружаются через Google Fonts. Если сайт должен работать без внешних ресурсов, портрет и шрифты потребуется сохранить локально и обновить ссылки.

## Гайды

- `fatigue-guide-free-demo.pdf` подключен как бесплатный файл для скачивания;
- `supplements-for-energy-demo.pdf` и `seed-cycling-demo.pdf` являются демонстрационными файлами и сейчас напрямую со страниц не открываются;
- предпросмотр платных гайдов формируется из текста в HTML;
- ссылки оплаты пока ведут на тестовые адреса `example.com`.

## Перед публикацией

- заменить тестовые ссылки оплаты на реальные;
- подтвердить актуальность Instagram, Telegram и Calendly;
- решить, оставлять цены только в USD или добавить CAD;
- при необходимости перенести главную фотографию и Google Fonts в локальные assets.
