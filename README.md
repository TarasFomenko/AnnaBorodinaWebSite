# Anna Nutrition — Tilda Content Version

В этой версии я перенёс полезное со старого Tilda-сайта:

- реальные услуги;
- цены в USD;
- блок с врачебным опытом и образованием;
- запросы, с которыми можно обратиться;
- гайды;
- iHerb-код;
- дисклеймер;
- RU / EN / UA страницы.

## Файлы

- `index.html` — русский
- `en.html` — английский
- `ua.html` — украинский
- `style.css` — общий стиль
- `script.js` — меню, FAQ, форма

## Важно про фото

Фото подключены по ссылкам с Tilda CDN. Если фото не загрузятся локально или после публикации, лучше скачать оригинальные фото со старого сайта и заменить ссылки в HTML на локальные файлы:

```html
<img class="portrait-image" src="assets/anna-portrait.png" alt="Anna Borodina" />
```

## Что заменить перед публикацией

- Telegram-ссылку;
- реальные кнопки оплаты для гайдов;
- если нужно — валюту USD на CAD;
- тексты, если Анна хочет звучать мягче/официальнее.


## Исправления в этой версии

- `Шаг к здоровью / Step to Health / Крок до здоров’я` стоит первым слева.
- Блок цены и кнопки закреплён внизу карточки, поэтому цены не прыгают из-за разной длины текста.
- Кнопка записи без стрелки и в рамке.
- Зачёркнутая цена не переносится на две строки.
- Сумма крупная, USD меньше.
